# 后台意见反馈列表实施计划

日期：2026-07-29

## 1. 后端查询能力

- 扩展意见反馈 DTO，解析并校验分页、关键词、身份和时间范围。
- 扩展反馈服务，关联用户数据并按提交时间倒序分页。
- 新增后台查询路由，仅要求管理员登录，不限制为超级管理员。
- 在 OpenAPI 中补充后台意见反馈列表接口。

## 2. 后端测试

- 覆盖关键词同时匹配昵称和内容。
- 覆盖业主/小区外人员身份筛选。
- 覆盖时间范围、默认排序和分页。
- 覆盖 `ADMIN`、`SUPERADMIN` 可访问以及未登录 401。
- 覆盖返回字段不泄露 OpenID 等无关用户信息。

## 3. 后台页面

- 新增意见反馈类型和 API 请求方法。
- 新增后台路由与侧边栏入口，两类管理员均可见。
- 使用统一页面标题、筛选面板和卡片列表组件。
- 实现关键词、身份、时间范围查询以及重置、刷新、分页和错误空态。
- 使用统一默认头像和身份标签。

## 4. 后台测试
