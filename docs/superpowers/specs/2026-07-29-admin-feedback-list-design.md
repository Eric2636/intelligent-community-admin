# 后台意见反馈列表设计

日期：2026-07-29

## 目标

在后台管理系统新增“意见反馈”功能，让超级管理员和平台管理员可以统一查看小程序用户提交的意见反馈。

## 范围

- 新增独立的“意见反馈”菜单和页面。
- 页面只提供查询和浏览，不增加处理状态、处理备注、修改或删除功能。
- 小程序现有反馈提交能力保持不变，不增加标题字段。

## 权限

- `SUPERADMIN` 和 `ADMIN` 均可访问页面和查询接口。
- 未登录请求返回 401。
- 页面和后端接口同时校验登录状态，避免仅依赖前端菜单控制。

## 查询与展示

- 默认按提交时间倒序分页。
- 支持关键词搜索，关键词同时匹配用户昵称和反馈内容。
- 支持用户身份筛选：业主、小区外人员。
- 支持提交时间范围筛选。
- 卡片展示用户头像（无头像时使用统一默认头像）、昵称、身份标签、反馈内容和提交时间。
- 查询失败时清空旧数据并展示明确错误状态，避免误将缓存数据当成最新结果。
- 搜索框支持 Enter 查询，提供查询、重置和刷新操作。

## 后端接口

- 新增 `GET /api/admin/feedbacks`。
- 查询参数：`page`、`pageSize`、`keyword`、`identity`、`startAt`、`endAt`。
- 返回统一分页结构：`{ total, list }`。
- 列表查询关联用户信息，但不改变反馈表结构。
- 请求由现有接口访问日志中间件记录；只读查询不写操作审计。
